# Add a "Docs" link to the main navigation

Add a "Docs" link to the top navigation bar of the signed-in Langfuse
UI that opens https://langfuse.com/docs in a new tab.

## How to reach the app

Langfuse runs on http://localhost:3000. First-time use requires signing
up a new account via the /auth/sign-up page.

## Acceptance

- A "Docs" link is visible in the top nav on any signed-in page.
- Clicking it opens https://langfuse.com/docs in a new tab
  (target=_blank, rel=noopener).
- No other nav items are moved or removed.
